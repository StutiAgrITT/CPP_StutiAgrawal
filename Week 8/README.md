## Steps to run Program/Tests

### 1. Open Terminal
Navigate to the folder where this file is present.
`cd path/to/folder`

### 2. Create folder for playlists
`mkdir data`

### 3. Build the Project
`mkdir build`
`cd build`
`cmake ..`
`make`
`cd ..`

### 4. Run the Program
`./build/playlist_app`

### 5. Run the Tests
`./build/playlist_tests`
