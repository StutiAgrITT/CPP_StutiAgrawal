## Steps to Run main.cpp

### 1. Open Terminal
Navigate to the folder where this file is present.
`cd path/to/folder`

### 2. Download library for XML Parsing
`sudo apt update`
`sudo apt install libtinyxml2-dev`

### 3. Give permission to run script
`chmod +x run.sh`

### 4. Run the Program
`./run.sh`
