## Steps to Run Tests

### 1. Open Terminal
Navigate to the folder where this file is present.
`cd path/to/folder`

### 2. Install Dependencies
`sudo apt update`
`sudo apt install libgtest-dev libgmock-dev`

### 3. Build the Project
`mkdir build`
`cd build`
`cmake ..`
`make`

### 4. Run the Tests
`./banking_tests`
